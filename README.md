# Toko Kopi Ali Landing Page

Premium React + TypeScript + Tailwind CSS + Framer Motion landing page inspired by the supplied Toko Kopi Ali Instagram visual direction.

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Replace before production

1. Replace placeholder Unsplash images with official Toko Kopi Ali photography.
2. Replace branch addresses/hours in `src/data/locations.ts`.
3. Replace GoFood / GrabFood / ShopeeFood placeholder links in `OrderOnline.tsx`.
4. Replace testimonial placeholders with verified reviews.
5. Add the official logo and Ali character artwork if available.
